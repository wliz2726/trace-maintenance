# Trace International - Página en mantenimiento

Proyecto estático listo para publicar en Vercel.

## Publicación rápida

1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos de esta carpeta.
3. En Vercel, selecciona "Add New Project".
4. Importa el repositorio.
5. No selecciones ningún framework.
6. Deja el directorio raíz como `./`.
7. Pulsa "Deploy".

## Dominio

Después del despliegue:

1. Abre el proyecto en Vercel.
2. Ve a "Settings" > "Domains".
3. Agrega `tracesolar.com` y `www.tracesolar.com`.
4. Coloca en GoDaddy únicamente los registros DNS indicados por Vercel.
5. No elimines registros MX o TXT relacionados con los correos.

## Logo

El archivo `logo-reference.jpg` se obtuvo de la imagen de referencia y puede verse algo borroso.
Cuando tengas el logo original, reemplaza ese archivo manteniendo el mismo nombre o cambia la ruta en `index.html`.
